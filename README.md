# DMIT 电信线路：CN2 GIA 与 9929/CMIN2 怎么选，哪个机房对电信最友好

搜“DMIT 电信线路”的人，问题通常很具体：我家里拉的是电信宽带，DMIT 那一堆 Pro、EB、T1 到底哪条是给我准备的？买错了会不会比直连美国还慢？

先给结论，再讲原因。电信用户要看的只有一条线：**Pro 系列**。它的电信去程和回程都走 AS4809，也就是中国电信 CN2 GIA。EB 系列是给移动和联通设计的，T1 系列压根没做中国方向优化。三条线的价差不算小，买错的代价是钱花了、晚高峰照样卡。

下面把三条线的路由、机房差异和当前价格逐项拆开讲。

## Pro、EB、T1 三条线，对电信分别意味着什么

DMIT 把自己的网络分成三档，命名规则是 `区域.产品线.档位`，比如 `LAX.AN5.Pro.TINY` 就是洛杉矶机房、Pro 线路、最小的那一档。自营 AS906，机房只有洛杉矶、香港、东京三个地方，不做全球铺点。

从官方产品页和多个测试资料的描述看，三条线对中国电信的路由是这样：

| 产品线 | 电信去程 | 电信回程 | 定位 |
| --- | --- | --- | --- |
| Pro（Premium） | CN2 GIA（AS4809） | CN2 GIA（AS4809） | 电信首选 |
| EB（Eyeball） | CN2 GIA | AS9929 / AS58807 负载均衡 | 移动、联通优先 |
| T1（Tier 1） | 无优化 | 无优化（走国际 BGP） | 面向海外用户 |

有个细节很多人漏掉：Pro 系列的 IPv6 回程并不走 GIA，而是走 9929 / CMIN2 动态负载。也就是说，如果你是用 IPv6 访问，Pro 和 EB 的实际体感差距会比价格差距小。真正把 Pro 和 EB 拉开距离的是 IPv4 回程。

EB 系列的情况值得单独说一句。它的电信回程并不是固定走 CMIN2，而是 AS9929 和 AS58807 之间做负载分配——有测评记录提到，DMIT 后来把电信方向部分路由到联通 9929，为的是缓解 CMIN2 晚高峰的跨网拥堵。这说明 EB 的电信体验不是不能看，只是它取决于负载均衡把你甩到哪条路上，不如 Pro 稳定可预期。

至于 T1，得单独提醒电信用户：它是国际线路，走 Telia、Zayo、Cogent 这类国际运营商，流量给得很大、价格也友好，但**完全不针对中国大陆做优化**。如果你冲着低价买了 T1，很可能出现“洛杉矶机房延迟比直连还高”的情况。T1 的正确受众是外贸站、面向海外用户的业务。

## 机房怎么选：香港延迟最低，洛杉矶性价比更好

同样是 Pro 线路，三个机房的电信表现差别很明显：

- **香港 Pro**：电信双程 CN2 GIA，联通走 AS9929，移动走 CMI。第三方测评给出的全国三网平均延迟大约 43ms，电信约 42ms。这是三个机房里对电信最友好的，也是价格最贵的。
- **日本 Pro**：回程 CN2 GIA，去程做优化，带宽固定 1Gbps。延迟介于香港和洛杉矶之间，适合东亚业务和流媒体中转场景。
- **洛杉矶 Pro**：三网回程 CN2 GIA，全国平均延迟大致在 130–180ms 区间。这个数字放在美国西海岸属于很好的水平，但和香港不是一个量级。

再往下还有一层坑：香港 EB 的电信去程是绕日本 NTT 的，回程才直连；香港 T1 接的是 RETN 国际线路。也就是说，香港机房便宜的那两档，恰好是最不适合电信用户的。想在香港节点享受 CN2 GIA，只能买 Pro。

所以选择顺序很清楚：预算够、延迟敏感，选香港 Pro；要资源多、性价比高，选洛杉矶 Pro；如果主要用户是移动或联通，才轮到 EB。

## 价格之外的几个关键条款

买 VPS 只看月费容易漏东西，DMIT 这边有几条直接影响使用体验的规则：

**超量限速而不是断网。** 洛杉矶 Pro 和 EB 系列在月流量跑完之后不会停机，而是降速继续跑，限速档位从 4Mbps 到 10Mbps 不等，具体看套餐。对偶尔超量的站点来说这比直接断网友好得多，但也别指望 4Mbps 能做重流量中转。

**支付与退款。** 支持支付宝、微信支付、PayPal 和信用卡，对国内用户没有障碍。退款走官方 TOS 里的 Refund Policy 条款，第三方整理的说法是 3 天内全额、30 天内按比例，具体条件和时限请以官方条款原文为准，别只看转载。

## 什么情况下不该买 Pro

Pro 不是默认答案，有几种情况选它并不划算。

你的宽带是移动或联通为主。EB 系列在移动方向是 CMIN2 双程，联通回程走 AS9929，价格比 Pro 低一截，流量还给得更多。为了用不上的电信 GIA 多付钱没有必要。

你只是想要一个海外 IP 跑轻量任务。T1 系列 WEE 档年付 $36.9 起，流量额度大得多，唯一的代价是没有中国优化。如果你的访问入口不在国内，这钱花得更值。

你的业务对延迟极度敏感，但预算有限。这种情况下香港 EB 会更实际——虽然电信去程绕日本，移动和联通体验不错，价格是香港 Pro 的六成左右。不要为了“必须 CN2 GIA”硬上香港 Pro 再抱怨贵。

## 几个常见问题

**Pro 一定比 EB 快吗？**
对电信的 IPv4 访问基本是，因为全程走 GIA，不依赖负载均衡。但 Pro 的 IPv6 回程同样走 9929 / CMIN2，和 EB 是一个池子，所以只测 IPv6 的话差距会缩小。

**洛杉矶 Pro 的实际速度是什么水平？**
第三方测评给出的是全国平均延迟大致 130–180ms，晚高峰表现比普通 BGP 线路稳定。这个区间的机器适合建站、远程办公、中转，不适合拿来做极致低延迟的实时应用。

**流量超了会怎样？**
降速，不停机。限速多少取决于你买的档位，从 4Mbps 到 10Mbps。想恢复高速只能等下个计费周期或者追加流量包。
